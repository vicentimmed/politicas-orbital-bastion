# Políticas — Orbital Bastion

Este repositório existe por um motivo só: **hospedar a política de privacidade
do jogo Orbital Bastion**, porque a Google Play exige uma URL pública e recusa a
publicação sem ela.

Ele é público e o repositório do jogo não é. Foi essa a razão de separá-los:
apontar o GitHub Pages para o repositório do jogo tornaria público, junto com a
página, todo o código, toda a arte e os documentos de projeto.

- **A página:** https://vicentimmed.github.io/politicas-orbital-bastion/
- **Fonte:** `index.html`, em português e inglês na mesma página.

## A página mudou em 02/09/2026, e a mudança foi grande

A versão anterior dizia que o jogo **não tinha servidor, não tinha conta, não
fazia conexão de rede e não coletava nada** — e isso deixou de ser verdade. O
jogo ganhou conta anônima, placar semanal, cópia do save na nuvem, dados de
partida da campanha e anúncios opcionais pelo AdMob.

Uma política que promete "não coletamos nada" enquanto o aplicativo coleta é
pior do que não ter política: é uma declaração falsa para as duas lojas. Por
isso a página foi reescrita inteira em vez de emendada.

**A regra que fica:** quando o que o jogo coleta mudar, esta página muda **no
mesmo momento**, e não depois. No repositório do jogo, o que descreve item a
item o que é coletado é `docs/FICHA_LOJA_DADOS.md`, e é de lá que esta página
deve ser derivada — nunca o contrário.
